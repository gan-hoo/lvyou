开发过程中 CI 发现并修复的问题：
- 预算提醒中一个表达式类型检查超时（编译错误）→ 拆分表达式。
- **iOS 26.2 运行时上 `Decimal ==` 对内部表示不同的相等数值返回 false**（净资产合计 1470 与 1470 比较不相等）。算术本身正确，但拆分合计校验、对账、完整性检查等依赖相等判断。已改为按数值比较（`isSameAmount(as:)`，相减判零），并让舍入结果使用紧凑表示；新增回归测试 `roundedSumsCompareEqual`。

真机反馈后修复（iOS 26 iPhone，App 语言为中文、手机为英文（澳大利亚））：
- **日期显示为英文（「November 2026」）**：界面文字跟随 App 语言，但日期 / 金额 / 数字格式跟随手机地区语言。新增 `AppLocale`（App 运行语言 + 手机地区），所有日期、金额、数字、图表坐标与系统日期选择器统一使用；新增测试 `formattingFollowsTheAppLanguageNotThePhone`。截图 11、12 在「中文 App + en_AU 手机」组合下显示「2026年11月」「下午 6:34」「¥」。
- **液态玻璃模式下净资产卡片底部出现灰色条**：卡片使用的是系统 `glassEffect`，但它位于 List 行内，玻璃自带的阴影被行边界裁切成一条灰带。内容卡片的玻璃现在限制在卡片自身形状内（标签栏、工具栏按钮、提示条仍使用系统玻璃）；截图 7、13 已确认灰带消失。
- **拆分页填完后无法收起键盘、无法点「完成」**：数字键盘没有 Return 键；合计不等于总额时「完成」直接置灰。现在所有数字键盘上方都有「完成」按钮，拖动列表也可收起键盘；拆分的第一项自动填入剩余金额（直到手动修改）；合计不一致时点「完成」可选择「把总额改为合计」或「调整某一项」；缺少分类或金额时在列表下方说明原因。版本号改为 3.0 (4) 以便区分。
- **新增：支出的折扣与手续费**（用户需求）：输入的金额为原价，实付 = 原价 − 折扣 + 手续费；折扣减少该分类支出（拆分时按比例分摊、合计精确）、不计为收入、不能为负或大于原价；手续费计入「手续费」分类。列表、详情、搜索、排序、换算均使用实付；退款默认原价 − 折扣；CSV 新增 Discount 列；备份格式升级为 4（旧备份仍可恢复）。新增 3 个测试，版本 3.0 (5)。截图 `2-entry` 中可见「折扣 / 手续费」输入行。
- **记账页数字用 App 键盘、文字用系统键盘**（用户反馈：折扣 / 手续费弹出系统数字键盘与 App 键盘叠在一起）：折扣、手续费、手动汇率、跨币种转账到账金额改为由 App 键盘输入（点选后高亮，支持 + −，点大金额切回）；输入收付款方 / 备注时 App 键盘和账户 / 日期行收起，只显示系统键盘，点「完成」恢复。新增测试 `keypadTypesIntoTheSelectedNumber`，版本 3.0 (6)。
- **新增：流水页月历**（用户需求）：月份汇总下方显示当月日历（右上角按钮可开关，默认开启）；每天显示当日支出（只有收入时显示绿色收入），按金额深浅着色，今天描边、未来日期变淡；金额跟随当前筛选与搜索、使用本位币。点某天只看当天流水，再点或「显示整月」恢复；空白日提供「在这天记一笔」（打开记账并预填该日期）。截图 `3-transactions`、`13-transactions-glass` 可见月历。版本 3.0 (7)。
- **五个主页面去掉大标题、流水页去掉月份下方的横线**（用户反馈）：资产 / 流水 / 统计 / 预算 / 设置不再显示标题文字（标题仍用于子页面返回按钮与旁白）；流水页月份、汇总、日历几行不再显示列表分隔线。截图 `1-assets`、`3-transactions` 已确认。版本 3.0 (8)。

## 4. 签名与 IPA

- CI 产出的是 **未签名 IPA**（`release/Tally-unsigned.ipa`）。它 **不能直接安装** 到 iPhone，需要用你自己的 Apple 开发者身份重新签名（Xcode、Sideloadly、AltStore 等），或在仓库中配置签名证书 Secrets 后运行 `Tally signed IPA` 工作流导出已签名 IPA。步骤见 README「签名与导出 IPA」「iPhone 真机安装」。
- 本次交付没有可用的签名证书与描述文件，因此 **没有** 导出已签名 IPA，也 **没有** 在真机上安装验证。

## 5. 已知问题与限制

1. IPA 未签名（见上）；没有在真机上验证过 Face ID、触感反馈和性能，只在模拟器上运行过；没有自动化 UI 交互测试。
2. 数据只保存在本机，没有 iCloud 同步（模型已按 CloudKit 要求设计，但未开启）。
3. 汇率不会自动更新：需要手动添加，或在「汇率」页手动下载欧洲央行参考汇率。早于最早一条汇率的日期使用最早的汇率；完全没有汇率的币种保持「待换算」。
4. 预算提醒是 App 内提示（Toast），不发送系统推送通知。
5. 周期交易在 App 启动和回到前台时入账，不在后台运行；自定义周期为「每 N 天 / 周 / 月 / 年」。
6. 切换语言需要重新打开 App（iOS 对单个 App 语言的限制）。
7. Liquid Glass 主题只有在 iOS 26 且用 Xcode 26 编译时才使用系统玻璃材质；更早系统使用半透明材质替代。系统列表行保持系统样式。
8. 切换主题、强调色、金额格式或「隐藏金额」会重建界面，当前页面的导航层级会回到根页面。
9. 备份与 CSV 导出文件未加密，需要自行妥善保存。
10. CSV 导入时，没有可用汇率的外币行不会被导入（会在结果中列出行号和原因）。
11. 流水页的筛选与搜索在主线程上对当前已加载的交易进行（统计、预算、净资产等重计算在后台线程）；交易数量很大（数万条）时流水页可能变慢。
12. iOS 26.2 运行时上 `Decimal ==` 对内部表示不同的相等数值可能返回 false（见第 1 节）。App 内的金额相等判断已全部改为按数值比较；如后续新增代码，请使用 `isSameAmount(as:)`。
