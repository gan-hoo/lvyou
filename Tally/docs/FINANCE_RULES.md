# Tally V3 — 财务业务规则

所有余额、统计、预算都由同一份交易数据（`LedgerEntry` + `TransactionSplit`）经 `FinanceEngine` 计算得出，任何页面都不保存金额副本。金额一律使用 `Decimal`。

## 1. 账户

| 类型 | 归类 | 余额符号 |
|---|---|---|
| 现金、日常银行卡、储蓄、电子钱包、多币种、投资、其他资产 | 资产 | 正数 = 拥有 |
| 信用卡、债务（贷款） | 负债 | 负数 = 欠款（界面显示为「应付 ¥X」） |

- **余额** = 初始余额 + 初始余额日期当天及之后的全部交易影响。早于初始余额日期的交易仍参与统计，但不改变余额（初始余额已包含它们）。
- **总资产** = 所有计入净资产账户中**正余额**之和（按当前汇率折算）。
- **总负债** = 所有计入净资产账户中**负余额**的绝对值之和。
- **净资产** = 总资产 − 总负债。资产账户透支、信用卡溢缴款按符号归类，不会重复扣减。
- 无可用汇率的账户显示「待折算」，不计入合计，**绝不假设汇率为 1**。
- **对账**：输入实际余额 → 若有差额，生成一笔「余额调整」交易（保留调整前余额与差额，可审计）。

## 2. 交易类型对余额与统计的影响

| 类型 | 账户余额 | 收入 | 支出 | 预算 |
|---|---|---|---|---|
| 支出 | 付款账户 −(金额 − 折扣 + 手续费) | – | +(金额 − 折扣)（按分类或拆分，折扣按比例分摊）；手续费计入「手续费」分类 | 计入 |
| 收入 | 账户 +金额 | +金额 | – | – |
| 转账 | 转出 −(金额+手续费)，转入 +实际到账金额 | – | 仅手续费计入（「手续费」分类） | 仅手续费 |
| 信用卡还款 | = 转入负债账户的转账：付款账户减少、应付款减少 | – | – | – |
| 退款 | 账户 +金额 | –（不是收入） | −金额（冲减原分类支出） | 冲减 |
| 余额调整 | 账户 ±差额 | – | – | – |

- 信用卡消费 = 支出（形成真实费用，同时应付款增加）；还款不再形成第二次消费。
- 支出的「金额」是原价。折扣不能为负、不能大于原价，它减少支出而不是收入；实付 = 原价 − 折扣 + 手续费。对这笔支出的退款默认金额为原价 − 折扣（手续费通常不退）。
- 禁止转账到同一账户。跨币种转账分别保存转出金额与实际到账金额。
- **拆分交易**：各拆分金额之和必须等于交易总额；统计与预算按拆分分类计算；账户余额只变化一次总额。
- 每笔交易与其拆分在一次 `save()` 中原子写入。

## 3. 多币种

- 每笔交易保存原币金额、原币种、日期、账户，以及保存时的**汇率快照**（本位币、汇率、折算额）。
- **期间统计**：快照本位币 = 当前本位币时直接使用快照；否则按交易日期当天生效的历史汇率换算；都没有则「待折算」并单独计数。
- **资产净值**：按最新可用汇率估值。
- 汇率来源：手动录入（可指定生效日期）、可选下载欧洲央行参考汇率、导入。无网络时照常原币记账。

## 4. 统计口径

- 期间：本周（周一开始）、本月、本年、自定义；可前后切换。
- 净结余 = 收入 − 支出（期间现金流），与「资产净值变化」不同，界面分别表述。
- 转账本金、信用卡还款本金、余额调整不计入收入或支出。
- 与上一周期对比时，进行中的周期只与上一周期**相同经过时长**比较。

## 5. 预算

- 周期：每月（起始日可设 1–28 日）、每周、每年、自定义天数。
- 已用 = 期间内计入预算的支出（含转账手续费）− 对应退款；分类预算按分类/拆分匹配；总预算可排除指定分类。
- 总预算与分类预算是同一批支出的不同视角，**不相加**。
- 结转：开启后，上一周期剩余（或超支）计入本周期额度。
- 剩余 = 额度 − 已用；超支时显示「超支 ¥X」而非负的可用额度。
- 每日建议额度 = 剩余 ÷ 本周期剩余天数（含今天）。
- 预算金额以创建时的本位币保存，评估时换算到当前本位币。

## 6. 周期交易

- 规则（每日 / 每周 / 每月 / 每年，可设间隔）与已发生交易分开保存。
- 仅在到期日到达后生成实际交易；未来计划不影响余额。
- 生成的交易记录规则 ID + 发生日期，重复启动不会重复入账。

## 7. 数据安全

- 删除需确认；交易修改、删除、余额调整、恢复备份写入操作记录（`AuditRecord`）。
- 备份为带版本号与 SHA-256 校验的 JSON；恢复时校验版本与校验和，可「合并（按 ID 去重）」或「替换全部」，均需明确确认。
- 数据完整性检查：拆分合计、转账账户、缺失账户、待折算交易、无效金额。
